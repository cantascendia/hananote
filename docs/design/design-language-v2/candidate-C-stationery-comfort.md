# 候选方向 C：治愈手账（Stationery Comfort）

> 阶段：Phase 0 设计语言探索 · 候选 C
> 立场：作者为 Notion stickers / Habitica / Wallaby / 雑貨 系视觉设计师
> 与方向 A（编辑级东亚）、方向 B（科技隐私）形成对照
> 字数：约 2,200 字

---

## 1. 北极星（一句话定位）

**「翻开自己的小手账」**——把记录 HRT 这件本来有压力的事，包装成每天写一页贴满标签和水彩斑迹的私人日志，用纸张感和手绘痕迹替代医疗工具的冷感。

为什么不是 A 也不是 B：
- 方向 A（编辑级东亚）追求"杂志感的克制留白"，气质偏专业冷静——但 16-25 岁 MTF 用户每天面对身体焦虑，他们要的不是被 ELLE 编辑端着审视，而是有人陪。
- 方向 B（科技隐私）让"加密"变成视觉主角——但加密只是底盘，不该是用户每天看到的脸。
- C 是唯一愿意"暴露用户情绪"的方向。我赌情感连接，不赌精致冷感，也不赌技术感。

## 3. 色彩系统

### Light Mode

**纸张层（替代 v1 的"奶油白"）**

| Token | Hex | 取名 | 备注 |
|---|---|---|---|
| `background` | `#FBF6EC` | 旧纸米 | 比 v1 `#FFF8F1` 再暖 5° / 再哑 8%，更接近无印良品 MD 笔记本扉页 |
| `surfaceContainerLowest` | `#FFFCF5` | 新纸白 | 卡片置顶时浮起来一点点 |
| `surfaceContainerLow` | `#F5EFE2` | 米黄纸 | 列表底色 |
| `surfaceContainerHigh` | `#EBE3D2` | 牛皮纸 | 容器嵌套时再下沉一档 |
| `surfaceContainerHighest` | `#DDD3BD` | 包装纸 | 极少用，仅用于深嵌容器 |

5 级容器不再是单纯的明度阶差，而是模拟"纸张叠纸张"——略微偏色（米→黄→牛皮）让堆叠看起来不是 PS 图层，是真有质感的纸。

**墨水（文本主色）**

| Token | Hex | 取名 | 备注 |
|---|---|---|---|
| `onSurface` | `#2A1F18` | 钢笔棕墨 | 不是黑，是"日记本里写久了的钢笔字" |
| `onSurfaceVariant` | `#6B5849` | 旧字棕 | 时间戳/标签等次要文本 |
| `onSurface-blueInk`（特殊） | `#1A2C4D` | 蓝黑墨水 | 仅用于"日期"和"心情日记标题"——制造"今天换了支笔写"的微妙差异 |

**主色三件套（"可爱不腻"调色板）**

| Token | Hex | 取名 | 角色 |
|---|---|---|---|
| `primary` | `#D89AAE` | 木莓粉 | 比 v1 `#FFB7C5` 更深一档、更去糖化，像手账里"贴在标题上的胶带粉"，不是日漫泡泡糖粉 |
| `secondary` | `#A8C49A` | 抹茶绿 | "完成一项 todo"的勾叉色——必须有非粉色给到用户呼吸 |
| `tertiary` | `#E8C77B` | 蜂蜜黄 | 标签 / 高亮 / 成就时刻 |

**关键差异**：v1 是"粉+紫"双主色（樱色 + 薰衣草），C 是"粉+绿+黄"三主色——绿黄两色把"过于粉嫩"问题化解掉。这是 C 与 v1 最重要的化学差异之一。

**状态色（贴纸感）**

| Token | Hex | 取名 | 视觉处理 |
|---|---|---|---|
| `error` / `errorContainer` | `#C75D5D` / `#F4D4CC` | 朱砂红 / 樱桃汁 | 比 M3 默认 `#BA1A1A` 调粉一档，像盖了个"NG"印章 |
| `success` / `successContainer` | `#7FA86E` / `#D9E6CC` | 苔藓绿 / 抹茶奶 | 替代当前 `statusGreen` `#34D399`（Tailwind emerald 太电子）|
| `warning` / `warningContainer` | `#D89A4F` / `#F5E0BD` | 焦糖橘 / 蜂蜜奶 | 库存偏低 / 服药迟到时显示 |

## 4. 字体系统

| 角色 | 中文 | 西文 | 日文 | 备注 |
|---|---|---|---|---|
| Display / 大标题 | **思源宋体 Light** | **Caveat Variable** | **しっぽり明朝** | 衬线 + 手写让"日记气质"立刻成立。Caveat 不是花哨的字，是真的有人写字的笔感 |
| Headline / 页标题 | 思源黑体 Medium | **Quicksand Medium** | **M PLUS Rounded 1c** | Quicksand 圆角，比 v1 的 Plus Jakarta Sans 多一份温度 |
| Body / 正文 | 思源黑体 Regular | **Inter Regular** + **Lora Regular** 混排 | UD 圆体 R | Lora 的衬线让长段日记读起来"有书的味道" |
| Label / 标签字体 | **翩翩体（华文翩翩）** 或 **手书体** | Caveat Regular | しっぽり明朝 italic | 这是 C 独有的"标签字体"——专门用在 chip / tag / 时间戳上，制造"贴纸是手写的"错觉 |

**Type Ramp**（行高比 v1 更宽）：

| Slot | Size / Weight / Line Height | 备注 |
|---|---|---|
| `display-md` | 32 / 400 / 1.45 | 不再用 Bold——衬线 Light 才像写出来的字 |
| `headline-sm` | 22 / 500 / 1.55 | |
| `body-lg` | 17 / 400 / **1.75** | v1 是 1.5——加宽是为了让"读 = 翻日记"而不是"读 = 看 UI" |
| `label-md` | 13 / 500 / 1.4 / 字间距 +0.4px | 翩翩体在小字下需要呼吸 |

**CJK 兜底**：Android 系统已经带思源系列，无需额外打包字体；翩翩体仅在 iOS 默认存在，Android/Web 用 `霞鹜文楷` (LXGW WenKai) 替代——开源、变量字体、CJK 完整覆盖。

## 5. 装饰系统（C 独有的章节）

**这是 C 不是花笺加强版而是进化方向的核心证据**：v1 的装饰是"主色渐变 + 樱花花瓣 1 处粒子"——属于"主题色装饰"。C 把**纹理 / 插画 / 标签**升格为一等公民 token，与 color / type / spacing 同级。

### 5.1 水彩斑迹纹理 `HanaTexture.watercolor`

- 6 张半透明 PNG（800×800，72dpi 即可，sRGB），分别为木莓粉 / 抹茶绿 / 蜂蜜黄 × 浅深两档。
- 用法：每屏 0–2 处，叠在 `surfaceContainerLowest` 之上、内容之下，blend mode = `multiply` @ 18% 不透明度。
- 严禁用法：不在 List 每一行重复；不在 button / chip 等小元素上贴；不在 Input 聚焦时贴（会干扰阅读）。
- 出现位置示例：Today 屏顶部问候语左下角一片浅粉晕；空态插画卡背景一片抹茶晕。

### 5.2 手绘装饰小图标 `HanaIconography.handDrawn`

- 自绘 SVG 图标系统，约 32 个：药瓶 / 心 / 体温计 / 月亮 / 太阳 / 樱花 / 笔 / 胶带 / 别针 / 小箭头 / 墨水滴…
- 风格规范：**1.5px 圆头线条**，无填充或仅 30% 不饱和填色，**允许线条不闭合**（手绘感的关键）。
- 不替代 Material Icons 的功能性图标（导航栏、Action Bar 仍用 Material rounded），仅用于装饰位（空态、引导、标签内嵌、成就贴纸）。
- 工程预算：32 SVG @ ~1KB each = 32KB，gzip 后 <12KB，可全部内联到 dart 资源中。

### 5.3 标签 / 胶带系统 `HanaTape`

替代 v1 的扁平 chip——每个 tag 用半透明色块（主色 @ 30% 不透明度）+ **微旋转 -2° 至 +2°**（每次渲染时基于 tag id 取一个稳定 hash 决定角度，不能随机抖动）。
- "#今日"："#已完成"："#月经周期"："#新里程碑" 等系统标签都用这套。
- 用户也可在日记 / 测量 / 照片上自定义贴标签。
- 工程实现：`HanaTape({label, color, rotation?})`，`Transform.rotate(angle: rotation ?? _stableHash(label))`。

### 5.4 拼贴感 `HanaCollage`

- 照片记录的缩略图允许有 polaroid 边框（白色厚边 + 微旋转）或撕边（CSS-style 不规则 clip-path）。
- 时间线事件卡可被一张"贴纸"角标盖住一角（"已完成"印章 / 心形 / 数字戳）。
- 不是必选——用户在 settings 可以关掉"拼贴装饰"回到纯色块（见第 13 节风险 3）。

### 5.5 背景纸样式 `HanaPaper`（用户可选）

Settings 里给"背景纸"三选一：
- `paper.plain` 默认空白（旧纸米）
- `paper.grid` 5mm 网格（线条 `#E5DCC9` @ 60% 不透明度）
- `paper.line` 横线（行间距 1.6em × body-lg）

**这是把 v1 的"无线条原则"反过来用**——v1 拒绝任何分割线，C 允许整张背景就是一张格纸。气质从"高级编辑设计"翻转到"我自己的笔记本"。

## 6. 形状与节奏

- **圆角**：12–20px 分级。chip = 20px（贴纸感）/ card = 16px（笔记本卡）/ button = stadium（不变）/ input = 12px（笔记本输入框）。
- **间距 scale**：6 / 12 / 24 / 48（比 v1 的 8/16/24 略宽松，配合 1.75 行高）。
- **倾斜的允许**：标签可 ±2°，角标贴纸可 ±5°，整页内容主体不倾斜。这是**结构化的不对称**——每张卡仍然横平竖直，只有装饰元素允许"贴歪"。
- **不对称构图**：标题文字允许偏左 24px，副标题再偏左 12px——制造"手写时纸边没对齐"的错觉。

## 7. 仪式感时刻

| 时刻 | v1 当前 | C 治愈手账 |
|---|---|---|
| **App 启动** | Fade-in 闪屏 | **翻开本子动画**：上半屏从 35° 角往下翻盖到底部（230ms ease-out-cubic + 微震动）。第一次启动有 0.5s "叮"音效（可关）|
| **服药完成** | 樱花花瓣粒子 | **盖章效果**：先一个绿勾从右下用钢笔笔触 280ms 画出来，然后一枚朱砂"完了"圆章 ±10° 啪一声从屏外飞入并轻微弹跳（spring physics）。**不是花瓣**——花瓣属于樱花主题，与"手账"主题混搭会变成主题杂烩 |
| **时间线浏览** | 列表纵向滚动 | 滚动时每个时间戳卡轻微"翻起"（rotate Y 3° 然后回正），仿日记翻页 |
| **数据导出 PDF** | 直接生成下载 | 模拟"撕下一页"：选定的卡向上滑出 + 上方出现锯齿撕边 + 0.4s 后变成 PDF 图标 |
| **新建日记 / 测量** | 弹 BottomSheet | BottomSheet 带"翻起本页"动画，背景纸张样式继承用户在 settings 的选择 |
| **庆祝时刻**（HRT 30 / 100 / 365 天） | 无 | 弹一张可保存的"成就贴纸"，可选择贴到时间线对应那一天 |

**petal_celebration.dart 的命运**：保留动画骨架（OverlayEntry + CustomPainter + 物理参数化），替换粒子素材为"墨水溅射 + 抹茶绿 confetti 碎片 + 一枚印章"。这正是 design-system-audit.md §4 给出的预期——"动画骨架是通用的，视觉是身份锁的"。

## 8. 文案调性（Tone of Voice）

比 v1 更人格化。v1 的 ARB 已经有不错的底子（dailyQuote 系列就是 C 想要的方向），但 CTA 和操作反馈仍偏功能化。

| 场景 | v1 当前文案 (zh) | C 治愈手账（建议改写） |
|---|---|---|
| 服药 CTA | `"takeDose": "服药"` | `"takeDose": "今天的份"`（从命令式→手账记录式） |
| 服药完成 toast | `"medicationStatusTaken": "已记录服用"` | `"medicationStatusTaken": "✓ 今天又陪你过了一天"` |
| 时间线空态 | `"noTimelineEvents": "暂无时间线事件"` | `"noTimelineEvents": "新本子的第一页还空着，写点什么吧"` |
| 删除照片确认 | `"photoDeleteMessage": "这将同时删除加密文件和记录。"` | `"photoDeleteMessage": "这一页要撕掉吗？撕掉了就找不回来了。"` |
| 录入测量后反馈 | `"measurementRecorded": "已记录一次身体测量"` | `"measurementRecorded": "今天的身体记下了，明天会不一样的"` |
| 添加第一种药物 | `"addFirstDrugCta": "添加你的第一种药物"` | `"addFirstDrugCta": "贴上你的第一张药品贴纸"` |

**调性约束**（避免变成腻歪的星座号）：
- 第二人称"你"，不用"亲"/"宝"等亲密称呼
- 不卖焦虑，不施加"打卡"压力（比如不说"已坚持 X 天，别断！"，而说"已经记了 X 天，每一页都在"）
- 医疗术语保留中性（"剂量"不改"小份"、"血液检测"不改"小血液"）——可爱不能损害医疗准确性
- 中日英三语都需重写一遍，不能只翻译。日语版应保留"です・ます"礼貌体但允许微妙的可爱（参考 hobonichi 手帐的文案）。

## 9. 参考产品（5 个）

1. **hobonichi 手帐 / hobonichi.com** — 这是 C 最像的灵感源。日本"ほぼ日"手帐的产品哲学就是"把每一天变成可保存的小事"。HanaNote 借鉴的是其文案温度 + 排版呼吸感 + 不强迫的记录节奏。
2. **Notion stickers + Notion AI 默认头像系统** — 现代化"贴纸感"的标杆。Notion 把 emoji + sticker 做成可编辑的内容元数据，C 的 `HanaTape` 系统是同思路（标签即装饰）。
3. **Wallaby Travel Diary（iOS）** — 拼贴式旅行日记，照片 + 文字 + 贴纸混排。C 的"拼贴感"模式直接致敬。
4. **Habitica** — 把习惯打卡变成 RPG。HanaNote 不做 RPG，但 Habitica 的"完成 = 视觉奖励"机制是 C 的"盖章效果"灵感来源。
5. **moo notebooks / 雑貨杂志（如《&Premium》《暮しの手帖》）** — 纸张质感 / 排版 / 色彩调性的参照系。米黄纸 + 暖墨水 + 偶尔一抹水彩——这是 C 在物理世界的对应物。

> 反例（不参考）：Sanrio 联名 app（C 不是 Hello Kitty 包浆）、TRACE 紫粉 IG-lite（v1 已在该象限）、Clue 大圆环（太"工具图表"）。

## 10. 应用到 Today 屏幕（描述性）

打开 Today，**翻页动画**结束后看到：

- 顶部：旧纸米背景上叠一片极浅木莓粉水彩晕（左上 1/3）。问候语用衬线 Light 写"早上好，[用户昵称]"，下一行用 `onSurface-blueInk` 蓝黑墨水写"HRT 第 184 天"——制造"今天换了支笔写日期"的细节。
- 中段：「今日的份」一张大卡（surfaceContainerLowest 新纸白），里面 3 个药丸 chip 横排。每个 chip = 抹茶绿胶带感半透明矩形 + 翩翩体小字"戊酸雌二醇 4mg"+ 微 1° 旋转。已服药的 chip 上有一枚朱砂"完了"小章。
- 下段：「最近一周」时间线缩略，每个事件用一张极小 polaroid 卡（白厚边）+ 撕边日期标签。
- 底部：FAB "+" 按钮——但形态不是圆，是**钢笔图标**（手绘 SVG）+ 圆角矩形容器，按下时墨水从笔尖滴一滴然后绽开成菜单。

底部 Tab Bar 仍是 5 Tab（Today / 记录 / 轨迹 / 数据 / 我的），但每个图标用 `HanaIconography.handDrawn`——选中时图标下出现一笔木莓粉手绘下划线（不是色块背景）。

## 11. 应用到 Onboarding 屏幕

4 步引导都包装为"翻开新本子"叙事：

1. **Welcome**：「这是你的小本子」——背景一张闭合的牛皮纸笔记本封面 SVG，前景标题 + 副标题，CTA "翻开它"按下时执行翻页动画进入下一步。
2. **Set Name**：「这一页写上你的名字」——输入框样式是横线纸（背景 grid line），输入时光标是钢笔尖图标。
3. **Set HRT Date**：「你的旅程从哪一天开始？」——日期选择器伪装成"日历贴纸"，选中的日期被一枚蜂蜜黄圆章盖住。
4. **Add First Drug**：「贴上第一张药品贴纸」——药品模板列表里每个药都是一张胶带感卡（半透明主色 + 翩翩体药名），点击时该卡"飞到"上方"我的本子"位置。

**对比 A/B**：方向 A 大概会做"杂志开篇页"叙事（克制、留白），方向 B 大概会做"加密握手"叙事（钥匙、盾牌、密码强度条）。C 用的是"开本子"——这是 16-25 岁用户最熟悉的童年情感锚点。

## 12. 与 v1 花笺的对比表

| 维度 | v1 花笺（数码纸笺） | C 治愈手账（Stationery Comfort） |
|---|---|---|
| 北极星 | "数码纸笺，编辑感的健康日记" | "翻开自己的小手账" |
| 主色策略 | 樱色 + 薰衣草（粉+紫）双色 | 木莓粉 + 抹茶绿 + 蜂蜜黄（粉+绿+黄）三色 |
| 装饰强度 | 主色渐变 + 1 处花瓣粒子 | **纹理 / 插画 / 标签升格为 token 体系** |
| 文本墨水 | 暖深色 #1E1B17（接近黑） | 钢笔棕墨 #2A1F18 + 偶尔切换蓝黑墨水 #1A2C4D |
| 边界 | "无线条原则"——靠色块分层 | **允许整张背景是格纸**（用户可选）|
| 倾斜 | 全部对齐 | 装饰元素允许 ±2° / 角标 ±5° |
| 庆祝 | 樱花花瓣 | 钢笔勾 + 朱砂印章 |
| 字体 | Plus Jakarta Sans + BeVietnamPro，2 字重 | 思源宋体 Light + Caveat + 翩翩体 + Lora 衬线，**4 字族** |
| 行高 | body 1.5 | body 1.75 |
| 文案调性 | 中性温暖（dailyQuote 已是好基础） | **进一步人格化**——CTA 也手账化（"今天的份"代替"服药"）|
| 图标 | 全部 Material rounded | 功能图标 Material + 装饰图标手绘 SVG |
| 主屏构图 | 对齐网格 + 卡片堆叠 | 对齐网格但允许装饰偏移 + 拼贴 |

**结论**：C 不是 v1 的"换粉色版"。v1 是"杂志编辑做的健康日记"，C 是"用户自己的小本子"。两个北极星方向不同：v1 看着像作品集，C 看着像被翻得起毛边的手账。装饰系统升格 + 字体扩到 4 字族 + 标签胶带感 + 三主色（不是双主色）——这四点保证了 differentiation。

## 13. 风险与权衡

### 风险 1：与方向 A（编辑级东亚）在"温暖度"上模糊
- **现象**：A 也走暖色 + 留白，外行可能觉得 A 和 C "都温柔"。
- **缓解**：C 的 differentiator 在装饰强度（A 极简，C 装饰量大约 3 倍）+ 文案人格化程度（A 中性克制，C 主动陪聊）+ 字族数量（A 单族 1 字重，C 4 字族混排）。这三点是物理上无法混淆的。
- **判定准则**：把两个候选的 Today 屏并排截图，盲测 5 个用户问"哪个更像你 16 岁时贴满贴纸的笔记本"——如果分不出，就是 C 没做透。

### 风险 2：手绘装饰资源量大，工程成本增加
- **现象**：32 个 SVG + 6 张 PNG 纹理 + 3 套背景纸 + 翩翩体回退字体 = 估算总资源 +180KB（gzip 后 +60KB）。
- **缓解**：
  - SVG 全部内联到 dart const 字符串（无网络请求，无文件 IO）。
  - PNG 纹理用 WebP 压缩，6 张 ~30KB。
  - 翩翩体在 iOS 系统自带（0KB），Android/Web 用 LXGW WenKai 子集化（仅含 GB2312 + 常用日文，~600KB→可考虑按需下载）。
  - 启动性能：装饰 SVG 都是 CustomPainter / SvgPicture.string 渲染，不影响首屏 LCP。
- **预算**：base APK 增加 <500KB，符合 Cloudflare R2 分发预算。
- **不可缓解但接受**：如果用户禁用所有装饰（见风险 3 缓解），C 的工程投入有 30% 沉没。但这是值得的——可定制性本身就是产品力。

### 风险 3：可能被读为"过于女性化"，与跨性别用户身份认同的多元性产生张力
- **这是最重要的风险**。MTF 用户中有相当比例（推测 30-40%）反感被预设"女性 = 粉色 + 可爱"——这是身份认同被 cisnormative 标准劫持的痛点。如果 C 强制塞粉色装饰，会让一部分用户感到"这个 app 在告诉我应该喜欢什么"。
- **缓解**（强制设计要求）：
  - **Settings → 外观 → 装饰浓度**：三档（极简 / 标准 / 最大化）。极简档关闭水彩纹理 + 关闭背景纸 + 关闭标签倾斜 + chip 用扁平色块，回到接近 v1 花笺的视觉强度。
  - **Settings → 外观 → 主题色调**：除"木莓粉" default 外提供"薄荷"（抹茶绿主色）、"暮云"（蓝灰主色）、"焦糖"（蜂蜜黄主色）三个备选——用户可以选择"非粉色"的手账。
  - **文案性别中立**：所有 ARB 文案审查不出现"小公主 / 女孩子 / 妹妹"等预设性别词汇。"你"通用。
  - **庆祝特效可关**：盖章效果 / 撕页动画都允许在 settings 关闭，回到 fade 反馈。
- **判定准则**：上线前邀请 5 位 MTF 用户（来自不同的"风格自我表达"光谱——从极女性化到 androgynous 到偏男性化）做可用性测试，每位至少能找到一组装饰度配置让自己舒服。

### 风险 4：CJK 手写字体在小字号下可读性挑战
- **现象**：翩翩体 / 思源宋体 Light 在 13px label 下，CJK 复杂字（"鬱"/"瀰"）会糊成色块。
- **缓解**：
  - 翩翩体仅用于 label-md (13px) 且字间距 +0.4px——但**复杂字符回退到思源黑体 Regular**（Flutter `TextStyle.fontFamilyFallback`）。
  - 思源宋体 Light 仅用于 ≥22px 的 headline 以上层级，绝不下放到 body。
  - body-lg 仍用思源黑体 / Inter / UD 圆体——这些在小字下都过 WCAG 2.1 AA。
- **可读性测试**：必须在 Phase 2 widget 落地前，用最长用药名（如"环戊丙酸雌二醇肌注"）+ HRT 184 天 + 最长指标名做 13px 翩翩体 label golden test。

### 风险 5：i18n 文案重写工作量
- **现象**：调性升级要求 zh/en/ja 三语全部重写约 60 个用户可见 key（不是机翻，要文学化重写）。
- **缓解**：
  - 第 8 节列了 6 个最关键 key 的样例，相当于风格指南。
  - 雇 1 个日语母语 + 1 个中文创意写作背景的人花 ~20 小时分别审一遍。
  - 英文以"hobonichi 风的 affirming + 不卖焦虑"为基调，参考 TRACE 的 microcopy 但去掉过度励志。
  - 工程上零成本（仅改 .arb 文件，不需重新生成 freezed）。

## 14. 适合 / 不适合

### ✅ 适合
- **16-22 岁早期 HRT 用户**——情感波动大，"被陪伴"需求强，对手账 / 谷子 / 二次元文化亲和度高
- **东亚 / 东南亚华人 / 日本 MTF 用户**——文化背景里手账文化（hobonichi / Filofax / 国誉 Campus）已经是成熟语境
- **正在经历身份转型早期焦虑的用户**——需要"今天又陪你过了一天"这种主动情绪输出
- **小红书 / lofter / Instagram aesthetic 用户**——会主动截图分享自己的手账页

### ❌ 不适合
- **30+ 岁追求"严肃工具"气质的用户**——对装饰会有"幼稚"评价（缓解：装饰浓度极简档可弱化到接近方向 A）
- **职场场景需要在公共场所打开 app 的用户**——粉色 + 手绘容易被同事一眼识别身份（缓解：隐私模式 + 切换"暮云"蓝灰主题）
- **完全功能驱动的用户（"我只想吃药打卡"）**——会觉得装饰是 noise（适合方向 B 或方向 A）
- **强调"我不是女孩"身份认同的部分非二元 / 跨性别用户**——粉色作为预设的政治符号会触发反感（缓解：装饰浓度 + 主题色切换）

## 15. 决策推荐力度

**8 / 10**

理由：C 是三个候选里**唯一在情感连接上 all-in** 的方向，且装饰系统是真正的差异化护城河——A 和 B 都可以被对手在 6 个月内复刻调性，但"完整的手账装饰 token 体系 + 三主色 + 4 字族混排 + 文案重写"是结构性投入，难以山寨。

扣 2 分原因：
- 1 分扣在风险 3——粉色与身份认同的张力是真实存在的，需要装饰浓度 setting 的兜底设计完美落地，否则可能伤害一部分核心用户。
- 1 分扣在工程成本——装饰资源 + 字体回退 + 文案重写合计约 6-8 周工作量，比 A/B 都重。

**如果产品愿景的核心权重是"建立用户与 app 的情感关系"，C 是最强答案。如果权重是"显得专业可信" → 选 A。如果权重是"显得安全可信" → 选 B。**
